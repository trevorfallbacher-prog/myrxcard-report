QBR NPS — Deluge additions to push_avalon_case (revised 2026-08-24)
====================================================================
Paste this block into the Zoho CRM function push_avalon_case, AFTER the last
`row.put("other_fees", ...)` line and BEFORE `payload = Map();`.

Pushes ONLY the three fields provisioned in Xano + whitelisted in the worker:
nps_recommend, experience_score, survey_completed. Do NOT add other survey
fields here until their columns + worker whitelist entries exist — the worker
rejects the whole batch on any unexpected field.

Free-text survey comments are intentionally NOT sent (PHI stays behind the firewall).

// --- QBR satisfaction survey ---
if(rec.get("How_Likely_Are_You_To_Recommend_1_10") != null)
{
	row.put("nps_recommend",rec.get("How_Likely_Are_You_To_Recommend_1_10").toDecimal());
}
if(rec.get("How_was_your_overall_experience_1_5") != null)
{
	row.put("experience_score",rec.get("How_was_your_overall_experience_1_5").toDecimal());
}
if(rec.get("How_was_your_overall_experience_1_5") != null || rec.get("How_Likely_Are_You_To_Recommend_1_10") != null)
{
	row.put("survey_completed","yes");
}

DEPLOY ORDER (important):
1. Xano columns — DONE (nps_recommend, experience_score, survey_completed on table 12).
2. Deploy the worker with the widened whitelist (wrangler deploy in tools/sync-worker)
   — MUST happen before step 3, or pushes carrying the new fields get rejected.
3. Paste this block into Zoho push_avalon_case.
Then edit/save a case with a survey filled in (or run the backfill) → NPS flows
to Xano → the QBR "NPS Score" card populates automatically.
